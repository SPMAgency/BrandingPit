# The Branding Pit

An original auto-chess roguelite for phones and browsers. Recruit fighters by
defeating them in a 15-second Raid, merge and position them on a 12x8 hex arena,
and push a run to 12 wins against other players' saved ghost boards. Everyone 10+.

- Rules for every chat: `CLAUDE.md`
- Status board: `docs/STATUS.md`
- Who owns what: `docs/OWNERS.md`
- Kickoff prompts for the eight chats: `docs/prompts/`
- Playable Raid prototype: `prototype/raid.html` (open it in a browser)
