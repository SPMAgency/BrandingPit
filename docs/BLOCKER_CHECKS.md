# Blocker checks — pass or fail from phone recordings

Carried over from Blacktop Aether's Video chat method: **a phone bug is closed
when a recording of the fixed build passes its check, not when the code looks
right.** Owners fix; whoever measures (a QA/Video chat if Doctor Def opens one,
otherwise Engineering) only measures, frame by frame, and posts PASS or FAIL
with frame times on their board file.

## Recording rules for Doctor Def

- Screen-record on the phone at normal speed, the orientation that showed the
  bug, 60 to 120 seconds, profiler on where the check says.
- Send it to the measuring chat with the build number in the message.
- One "before" recording per blocker, one "after" per fix.
