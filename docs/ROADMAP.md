# Roadmap — from the hold to launch

Engineering, 2026-11-07. Milestones in order; each is proven on Doctor Def's
phone before the next starts (simplest version first). Dates are not set while
the game is on hold.

| Milestone | Done when | Main chats |
| --- | --- | --- |
| **M0 — Setup** | Repo, rules, board, owners, gates, CI, audit, closeout | Engineering — **done 2026-11-07** |
| **M1 — First real fighter** | Brasshorn baked and fighting in the Raid on the phone; the live game runs on `PitSim`; memory check with 16 fighters on screen passes on device | Character Dev, Animations, Actions/Functions, Engineering |
| **M2 — One full run** | Camp, Raid, ghost fight (AI board), boss every third battle, 12-win target, results; one fighter per class (8); audio placeholders on every event | all |
| **M3 — Commander** | Commander creator, phone-bake spike PASS (under 2 s, matches a Godot bake), magic attacks | Character Dev, Animations, Role Building |
| **M4 — Content complete** | Launch roster (25) baked; relics, magic, bosses, items, Pit Conditions live; the music in | all |
| **M5 — Online** | Ghost saving and matching live, age screen, under-13 rules, the balance job | Online & Accounts, Engineering |
| **M6 — Ship** | The three builds in `docs/PLAN_SHIP.md` | Engineering, Legal |

Rule carried from Blacktop: a feature that misses its milestone moves to the
next one; it never holds a milestone open.
